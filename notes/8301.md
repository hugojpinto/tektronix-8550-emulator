# 8301 MDU — hardware notes (from 070-2976-01 §1, §3, §7, §9, §16 + ROM disassembly)

System processor: Signetics 2650A-1 on the System Controller board. FAST clock 2 MHz (J5704), SLOW 1.25 MHz.
The 2650 sees 32 KB (A0–A14); the system bus is 64 KB (BA0–BA15) for system memory and program memory separately.

## CPU address space
| CPU addr | Maps to |
|---|---|
| 0000–07FF | **Boot ROM** 160-0728-01 when EA<5> = 0 (enabled by RESET) |
| 0000–0FFF | **Diag ROM** 160-0802-01 when EA<6> = 1 (overrides boot ROM) |
| 0000–1FFF | System RAM 0000–1FFF |
| 2000–3FFF | System RAM page (D3<7:5>)·2000. Power-up D3 = 0 → page 0 (alias!). The boot ROM writes D3 = 20 for identity |
| 4000–7FFF | 16 KB window: EE<2> = 1 system / 0 program memory, EE<1:0> = BA15:14 block. EE<3> = MAPEN. The boot ROM writes EE = 05 → system 4000–7FFF (linear 32 KB) |

The memory map / write-protect RAM sits at system-bus FE00–FFFF (bits D0/D2): 512 blocks of 128 B.
Both ROMs start with interleaved 2-byte vector pointers that also execute harmlessly (e.g. diag `00 81 00 87 …`).

## Boot flow (from ROM disassembly)
- RESET → boot ROM at 0000. It reads ED: switch 6 open → CFM/diag; else it checks the self-test state and normally enters the diag ROM (07e5: EA = 60, jump 05ac).
- ROM hand-over works by overlapping code at 07ec–07f9. In the diag ROM: `EA = 00` → the next fetch comes from the boot ROM (07f0 `bcta 0020` / 07f7 `bcta 05ac`).
- Boot init: ACIA master reset (03 → CE/CC/CA), terminal ACIA control 15, E9 = 0, EE = 05, D3 = 20, LEDs.
- OS hand-off: it copies `lodi 20; wrte ea; bcta *1819` to RAM 1800, so the boot ROM is unmapped and it jumps via the pointer at 1819.
- It programs DMA ch2 (94/95) and E9 = A0 for HSI transfers. Strings: "BOOT V2.1", "no boot file", "comm error?", "/KERNL", "8301/RESIDENT", "/DIAGS/EXEC".

## HSI protocol (observed between the real firmware/OS images in the emulator)
- Packets: `81 | 00 | len | 00 | 00 | a | 00 | b | checksum`, answered with `06` (ACK) or `15` (NAK). `02 … 03` frames carry data (e.g. `02 ff 05 00 00 0b 00 00 "8501 V1.0\n\r" 03`). `19` precedes requests.
- The 8301 boot ROM uses programmed I/O only. It sends a byte when E9 shows TBRE and CTS (mask 0x82). It sends a lone `00` when idle and TBRE.
- **Flow control is per byte:** the 8501 I/O board raises NCTS (RCSR<0>) on start-bit detect and clears it when RBUF is read (by the program or by DMA). The 8501 OS also sets NCTS itself before arming a receive DMA; the DMA then first drains the byte already waiting in RBUF.
- 8501 I/O board CSR<1> = 1 means **OUT** (from memory). The manual's wording is ambiguous; the OS behaviour settles it.
- Boot sequence seen: version message "8501 V1.0" → open `/VOL` → `SYSTEM` directory → `/VOL/SYSTEM/8301/RESIDENT` → ~100 KB loaded → banner **"DOS/50 V1.0   18-AUG-80"**.

## After the banner: Language Processor probe
DOS/50 (code at 6586) disables program-memory relocation (B8/B9 = 50) and writes the Z80 program `06 00 10 fe 76 76 76 76` (LD B,0; DJNZ $; HALT) to program memory 0000. It writes F9 = FA (debug command), clears ports E0–E5 / A0–A5 (optional boards), sets C3/C4/C6, E7 = 80 (Language Processor active), then **HALTs the 2650**.
The "emulator halted" interrupt (vector 36 → handler 681e) reads F2 (active-low pending bits; D4 = emulator halt) and sets 6d1d<4>. The loop retries until it sees it. ⇒ The Language Processor (Z80) and the Emulator Controller's halt detection are required to get past the banner.

## Language Processor / Emulator Controller (as implemented)
- The Z80 (LP) runs from program memory only while the 2650 is HALTed and E7<7> = 1. Any interrupt that wakes the 2650 stops it (master/slave; one CPU on the bus at a time).
- F9 write: D0 = 0 forced reset (Z80 PC = 0, clears pending), D2 = 0 forced jump (PC ← FB:FA), D3 = 1 debug interrupts enabled, D4 = 1 SVC enable.
- SVC n = Z80 `OUT (F8h−n),A` + NOP, for n = 1…8 (ports F7…F0; block relocatable via F3). It raises 2650 interrupt 15+n (vectors 20…2E). The SRB pointer for SVC n is at program memory 40h + 2(n−1) (SAS format).
- Z80 HALT → "slave halted", F2<4> (read active low), interrupt 27 (vector 36).
- Program↔system memory copies for SRBs use 8257 ch0 → ch1 with E9<0>/<6> selecting the source/destination memory.
- Editors and assemblers (EDIT, ASM) are Z80 programs that run on the LP and talk to DOS/50 through SVCs.

## Validated against the 8550 Disk-Resident Diagnostic System 2.4 (062-5412-08)
With `tek8550 -pm ext`, Automatic System Verification passes with zero errors: System Processor & I/O 1.4, Memory 1.4, Language Processor 1.2 (all 14 modules incl. Emulator Controller SVC/single-cycle/BP1/BP2), DMU 1.2 (1000+ s device interaction). RTPA/MAC/TTA are correctly reported absent.
Facts established on the way (beyond the manual):
- Unmapped I/O ports read **00**; the diag configuration probe treats 00 as "board absent".
- When the 2650 HALTs and **no slave is enabled** (E7<7> = 0), the Emulator Controller reports "slave halted" at once (as described under the Processor Inactive Test).
- Emulator Controller events: SVC immediate; BP1 > BP2 > single-cycle > halt are issued after the instruction ("at the next fetch"). The slave is paused while one is outstanding; an F9 write releases it. F8 bits are active low (0 = enable).
- **Breakpoint registers FC–FF (and F6/F7) are loaded active-low.** PC next/last read back true.
- **F4 (extended bank) is active low:** the diag sweeps FF, FE, … and FF selects bank 00. The program-memory boards are strapped at bank 00. The 8257 DMA and the Language Processor do not use F4.
- **Two program-memory board generations:** DOS/50 V1.0 (1980) writes F4 = 00 and B8 = 10, which only works on boards **without** the extended comparator (default). The 1981+ boards with the comparator (B8/B9 D6) are needed by the 1983 diag (`-pm ext`).
- **SENSE input** carries a ~25 Hz square wave (20 ms half period), used by the processor-speed test (expects "2 MHz").
- 2650 timing: a taken RETC costs no extra cycles (MAME adds 2); the interval-timer test requires the corrected timing.
- Parity interrupt (vector 1) and the error-address latch stay set until D2 is read (first error wins).
- 8501: the LSI-11 budget is 3.1 M T11 units/s, calibrated with the disk LTC test's 1-second loop (28100 × 108 units).
